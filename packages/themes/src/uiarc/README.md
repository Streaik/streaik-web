# UI Arc JSON viewer

Vendored from the free [UI Arc shadcn registry](https://uiarc.dev/components/json-viewer), using the [JSON viewer](https://uiarc.dev/r/json-viewer.json) and [motion tokens](https://uiarc.dev/r/arc-motion-tokens.json) items.
